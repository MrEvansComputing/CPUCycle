# CPU Mission HQ

Static GitHub Pages extension site for Year 10 Computer Science.

## Pages
- `index.html` — home / progress
- `lesson1.html` — Boot Sequence: secondary storage → RAM → CPU
- `lesson2.html` — CPU Control Room: CU, ALU, registers, clock, buses
- `lesson3.html` — Fetch Protocol
- `arena.html` — harder fast-finisher challenges

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the site URL.

No frameworks, packages or build step are required.
Progress is saved locally in the student's browser with localStorage.
