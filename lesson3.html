Fetch Protocol

Fetch only. No named-register overload. Focus on what travels, where it travels and why.

Mission 1 — Address or instruction?

The CPU needs the instruction stored at memory location 40. What travels first from the CPU toward RAM?

Mission 2 — Fetch relay

Put the simplified fetch sequence in order.

RAM sends the instruction back on the data bus
CPU sends the required memory address on the address bus
Control Unit sends a memory-read signal on the control bus

Mission 3 — Debug the explanation

“During fetch, the CPU sends the instruction number along the data bus to RAM. RAM then sends the memory address back on the address bus.”
What is the main correction?

Mission 4 — System failure simulator

The address bus fails. What is the best consequence?
The data bus fails during fetch. What is the most direct problem?

Mission 5 — 20-second explanation
